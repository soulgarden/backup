Inspect the scheduled backup:
  kubectl --namespace {{ .Release.Namespace }} get cronjob {{ include "backup.fullname" . }}

Run a backup manually:
  kubectl --namespace {{ .Release.Namespace }} create job --from=cronjob/{{ include "backup.fullname" . }} {{ include "backup.fullname" . | trunc 40 | trimSuffix "-" }}-manual-$(date +%s)

Only the public schema is included in each dump.
